# ChatGPT AI Chatbot – Kotlin Android App

This is a Kotlin Android application built in Android Studio that shows how to integrate Kotlin with OpenAI's ChatGPT API to create an AI-powered chatbot.

---

## **Tech Stack**
**Kotlin** – Android Native Development  
**ChatGPT API (OpenAI)** – For generating AI responses  
**Coroutines** – For asynchronous processing
